# 📦 离线PDF工具箱 V7.4

> 纯离线 · 零上传 · 全免费 · 免安装 · 全平台通用

一个完全运行在浏览器端的 PDF 处理工具集。**现已升级为44 项功能**，无需安装软件，无需上传文件，打开就能用。

## 📦 更新日志

### [V7.4] - 2026-11-20

#### 新增

- 🧽 **删除水印**（1 个模块）：自动扫描全文，按字号异常 / 半透明 / 非黑色 / 旋转 / 不可见 / Artifact / 每页重复七类特征打分，勾选后一次移除，支持删除前后预览，导出「原名_已去水印.pdf」。支持内容流文字与图片水印、Form XObject 内嵌、OC 可选内容层、注释型（FreeText / Stamp）水印，以及整页半透明图水印。开发中同步处理了若干兼容问题：部分来源的 `File.type` 为空串导致文件被静默拒绝、正文基准字号被大字水印抬高、内联图片水印未纳入统计、Form XObject 缺 `/Subtype` 被整段跳过。
- 🎨 **页面滤镜「漂白」保原始分辨率**（1 个模块）：按图片原始像素反推有效 DPI 重建，不再压到固定 DPI 导致糊字。
- 🖼️ **图片转 PDF 纸张方向 / 放置方式**（1 个模块）：可选纵向或横向，图片按适应 / 填充 / 原始尺寸放置。
- 📄 **页面重排「替换选中页」**（1 个模块）：把一张页面直接替换到当前选中位置。
- ⬜ **补齐空白页三种插入方式**（1 个模块）：补齐到偶数 / 指定位置插入 / 隔页插入，三种方式用单选框切换；「指定位置」与「隔页」均可选择插在该页之前或之后，插入页与前后页同尺寸。
- 🔍 **大图预览分辨率提升 + 滚轮缩放**（19 个使用 XPrev / 全局预览浮层的模块）：大图不再固定按 1.5 倍（108 DPI）渲染，改为按浮层实际尺寸 × 设备像素比动态请求，A4 页从 892×1263 提升到 2985×4224（约 361 DPI，大屏可达 700+）；预览框改为占满视口 88vw×82vh，放大后右侧与下方内容可通过拖拽平移查看；支持鼠标滚轮以光标为锚点缩放（上限 8 倍，放大时按需补渲染更高清版本）、双击复位或放大 2 倍、键盘 `+` / `-` / `0` 控制；大图缓存只保留当前页 ±1，200 页文档实测 JS 堆仅 43 MB。
- 📐 **分辨率选择器统一为 DPI**（13 处）：合并·发票、统一页面大小、拆分对开页、倾斜校正、裁剪白边·预览、裁剪白边·导出、图片转PDF、PDF 扁平化、页面滤镜、工程蓝图、模拟扫描件、PDF压缩、PDF涂黑。上限 1200。
- 🖱️ **回首页清空搜索并置顶**（1 处交互）：点「所有工具」或左上角 logo 回首页时，自动清空搜索关键词并回到页面顶端，不再只剩上次的过滤结果。
- 🔎 **自动删除空白页检测增强**（1 个模块）：新增**「忽略页边」**（统计时裁掉上下各 N%，避开页眉页脚，扫描件的页眉页脚是像素、文本保护挡不住）与**「去噪」**（3×3 均值卷积压掉扫描噪点，避免噪点被判成墨迹导致空白页检不出）；两项改变的是像素统计本身，调整后自动重跑检测。新增**手动勾选保护**：用户亲手勾选或取消过的页，在调整阈值、文本下限、保护开关后不再被重置回默认值（旧版每次调参数都重算全部页的勾选，逐页复核十几页后一调阈值就全白勾）。
- 🔄 **统一页面大小「页面方向」**（1 个模块）：新增方向选项，默认**跟随原页**——原页横向输出横向、纵向输出纵向，不再把所有页塞进同一个纵向纸（旧版横向页被等比缩小、上下留白）；另可选「全部纵向」「全部横向」。预览、目标尺寸判定、「尺寸一致则直接复制」的快速路径均已改为逐页计算。
- 🔢 **添加页码「九宫格位置 + 文字旋转」**（1 个模块）：位置由「左/中/右」三态改为**九宫格点选**（9 个格子，选中高亮，格内小横条示意摆放位置），覆盖页眉、页脚、页边全部九个落点；边距改为「距左/右边缘」「距上/下边缘」两个动态标签输入框，选中间列或中间行时对应框自动禁用并提示居中。新增**页码方向** 0° / 90° / 180° / 270°，用于横竖混排文档。旋转后的锚点按「包围盒中心对齐」反推，保证转完仍在选定角落；页面 /Rotate 补偿角与用户角度**叠加**而非覆盖。
- 🈶 **添加页码「中文样式」**（1 个模块）：新增「第 {num} 页」「第 {num} 页 / 共 {total} 页」「第 {num} 页，共 {total} 页」三种中文样式，宋体渲染。pdf-lib 的精简构建没有 fontkit，内置字体写中文会被静默写成问号（实测 `第1页` → `?1?`）；而中文字体文件 9~18MB，内嵌会让单文件体积翻几倍。因此**只把中文样式转成 PNG 图片嵌入**，英文与数字样式保持真文字。5 页文档实测体积仅增加 15KB，字号 14pt 按 6 倍超采样渲染，放大和打印都清晰。
- 🔢 **页面重排「手动输入排序」**（1 个模块）：新增「拖拽排序 / 手动输入排序」二选一的排序方式。手动输入按输出顺序填写原页码（如 `5,2,2,3,1`），重复合法（同一页输出多次）、未列出的页不输出（数据保留，可重新输入取回）；分隔符支持逗号、顿号、空格并实时统一为半角逗号；越界/非法字符/0/空输入均给出明确错误提示；应用后缩略图角标显示「原 P5 → 新P1」（新序号红字）。两种模式互斥，切回拖拽时顺序回到原始；手动输入仅支持单文件，多文件时自动置灰并说明原因。

#### 优化

- 🎛️ **缩略图网格统一到共用组件 `XPrev`（9 个模块）**：小册子拆分、删除页面、自动删空白页、页面旋转·批量、页面旋转·逐页、提取图片、PDF转图片、图片转PDF、页面重排。选中样式、缩放按钮、加载态全站一致。迁移时逐页旋转改用组件内的角度累计（`rotAccum`），连点可依次 90°→180°→270°→0°→90°（旧实现每页角度存在业务侧 `pageRotations[]`，组件读不到，点第二次仍是 90°）。
- 🖼️ **页面预览框统一到共用组件 `XPageView`（19 个模块）**：页面拼版、小册子排版、统一页面大小、拆分对开页、倾斜校正、裁剪白边、生成空白 PDF、页面滤镜、工程蓝图、模拟扫描件、添加页码、Bates 编页、文字水印、图片水印、添加图章、扇形骑缝章、批注、添加 / 编辑书签、PDF涂黑。翻页条、缩放、适应窗口、高度拖拽、`←/→` 翻页全站一致。
- ⚡ **大文档预览性能**：改为分组渲染 + 渐进上屏 + 自适应倍率，几百页不再白屏等待（涉及页面重排、PDF 转图片、提取图片 3 个模块）。
- 🧹 **清理死代码与重复逻辑**：移除迁移后遗留的旧预览代码与未引用样式（清掉 `#tab-redact .red-canvas-container`、`.red-stage`、`#red-canvas` 三处已废弃样式）。
- 🔢 **自动删除空白页「像素阈值」改为可编辑数字框**（1 个模块）：阈值右侧原本是只读数值，只能拖滑块粗略调整；改为数字框与滑块**双向联动**，可直接输入精确值。输入过程中不夹值（否则打断输入），失焦或回车才夹到 0~5 区间。
- 📏 **裁剪白边「微调」范围与成对校验**（1 个模块）：上限由 ±35mm 提到 **±200mm**（16 组滑块与数字框同步）。新增成对校验：上＋下不得超过页面高度、左＋右不得超过页面宽度，超出部分自动截断（A4 实测上 200 + 下 96.6 = 296.6mm、左 150 + 右 59.6 = 209.6mm）。
- 🎯 **裁剪白边「微调」语义重构为「距纸边内缩」**（1 个模块）：数值含义由「相对检测到的内容边界的偏移」改为「**距纸边的内缩距离**」——`0 = 纸边`、正数 = 往里裁，**负数概念整个消失**（原来想裁到纸顶要填 -40 这类反直觉的值）。打开文件时自动把检测到的内容边距填入四个框，看到的就是实际边距；范围改为 0~200mm。同时修复**上下/左右可以调颠倒**的问题：旧实现在上边越过下边时会把两条边**静默对调**，导出一块反过来的区域；新实现约束「上+下 ≤ 页高、左+右 ≤ 页宽」，越界直接截断，裁剪框尺寸恒为非负。
- 📜 **许可协议与第三方声明整改**：统一版本号，许可条款改为写在文件头注释里、单文件分发即可自洽（无需另附 LICENSE），补齐中英文对照与 pako 声明。

#### 修复

- 修复**添加页码**在 Times Roman / Courier 下预览字形与导出不一致——字体族名带空格未加引号，浏览器丢弃整条 `ctx.font` 后回落衬线体。
- 修复**重建文档时丢失书签与元数据**：拆分、合并、重排等重建类操作会带上原书签大纲与文档信息。
- 修复**加密文档**处理直接失败，改为自动识别并提示。
- 修复**共享图片提取不到**：同一张图被多页复用时会被漏掉。
- 修复**自动删除空白页**误删风险：判据扩为墨迹 / 文本 / 纸底噪声 / 文档类型四道，扫描件纸底与纯页码页不再误判。
- 修复**压缩**在部分文件上反而变大——压缩后更大就保留原图。
- 修复**页面尺寸随 DPI 变化**：调整导出 DPI 时纸张尺寸不再跟着放大。
- 修复**扫描件被无谓放大重采样**（7 个栅格化模块）：统一页面大小、PDF 扁平化、模拟扫描件、工程蓝图、倾斜校正、PDF压缩（栅格化档）、PDF涂黑，改为按页面内嵌图像的原生像素封顶，扫描件不再被抬到所选 DPI 之上——不增加任何细节，只让体积成倍膨胀（实测最高 3.51×）。矢量页与图文混排自动回落所选 DPI，清晰度不受影响。PDF 扁平化是例外：它的语义就是按用户选定分辨率转图片，不参与该压制，150 / 300 / 600 / 1200 四档分别输出 1240×1754 / 2480×3508 / 4961×7016 / 9921×14032。
- 修复**压缩·矢量保真模式**对数组型内容流（`/Filter [/ASCII85Decode /FlateDecode]`）与无 `/Filter` 的未压缩流处理不全：前者被静默跳过，后者被整段忽略——这两类恰恰是收益最高的流。现按 Filter 链逐级解码，Flate / ASCII85 / ASCIIHex 全部支持。
- 修复**模块总数与分类计数不准**：实际 44 项功能，「标注与编号」实为 8 项（原标签误写 7 项），同步修正标题、首页分类标签、关于页与 README。
- 修复**点卡片进入功能面板后顶部 Tab 高亮不跟随**：已在合并面板，顶部「所有工具」仍显示为高亮，容易误以为还在工具总览页。现进入功能面板时清掉 Tab 高亮，让高亮如实反映当前位置。
- 修复**单文件分发时许可声明指向不存在的文件**：原文写「依随附 LICENSE 授权」，但实际发布只发单个 HTML。现把完整条款写进文件头注释，单文件即可自洽，并补齐中英文对照。
- 修复**裁剪白边**功能说明被挤到打开文件窗口下方：面板内联样式把说明列写成 `flex:1 1 900px; max-width:900px`，与上传列（340px）相加超出容器导致换行；删掉内联覆盖回到全局 660px，恢复左右并排。

### [V7.3] - 2026-11-05

- 修复**图片后缀名与实际格式不符**导致合并失败（典型例子：文件名是 `.png`，文件头却是 `FF D8 FF` 的 JPEG）。浏览器按扩展名推断 `file.type`，原代码据此选 `embedPng` / `embedJpg`，把 JPEG 字节交给 `embedPng` 会被 pdf-lib 拒绝，该图片被记为失败文件，现在伪装的 JPEG 现在能正常合并。

  

### [V7.2] - 2026-11-03

#### 新增

- 📄 **PDF 提取文本**：读取 PDF 的**文字层**，按文字坐标还原阅读顺序，尽量减少串行；页与页之间可插入「第 N 页」标题行、分隔线或什么都不插；可勾选「保留段落」，也可整段拼接不换行。结果直接显示在页面里，支持**一键复制**与**保存 UTF-8 TXT**（带 BOM，Windows 记事本直接可读）。已提取后再调整分隔符 / 排版只重组缓存文本，不重复解析文件。不修改原文件。
- 📑 **添加 / 编辑书签**：左侧书签树、右侧页面预览，工具栏在预览上方。打开 PDF 时自动读入原有大纲，可新增、删除、双击改名，随时调整目标页与颜色；上移 / 下移只调整同级顺序，「设为子项 / 提升一级」调整层级。书签颜色会写入 PDF，Acrobat 中即显示为彩色书签，重新打开也能读回。支持导出 / 导入书签 JSON、撤销 / 重做（60 步）、按标题搜索；保存生成「原名-书签.pdf」，原文件不变。

#### 界面统一（贯穿全站 42 个模块）

- **模块页面两段式骨架**：上段「左上传窗口（340px）+ 右功能说明（≤660px）」，下段「左设置列（300px）+ 右预览区」。页面重排、倒序、补齐空白页、删除页面、自动删空白页、批量 / 逐页旋转、页面拼版、小册子排版 / 拆分、裁剪白边等模块全部按此重排。
- **参数分组**：同一模块的参数按语义收进浅底圆角框（全站 43 组），不再平铺成长条。
- **预览窗口统一**：高度统一为 `clamp(420px, calc(100vh - 300px), 720px)`——大屏 720、矮屏自动收缩，保证预览和操作按钮同屏；带翻页的模块统一为「左翻页组 / 右缩放或提示」工具条，只翻页的模块不再出现多余缩放按钮。
- **页码文案统一**：全部改为「第 N / M 页」。
- **模块页标题加收藏星标**：42 个模块主界面标题旁可直接收藏，与首页卡片、收藏夹三处状态实时同步；星标紧贴标题文字，不飘到页面最右侧。
- **裁剪白边**：改为上下两段，下段三栏 2 : 2 : 6（白色容差 / 微调范围 / 预览），说明栏加宽到 400px；微调数值改为可直接输入的毫米数字框，与滑块、拖动预览框三者实时双向同步。
- **小册子拆分**：切分方向三个选项各占一行，左右栏比例 4 : 6；自动检测项注明「横图左右切、竖图上下切」。
- **其他修订**：页面拼版「不足处理」与「边距」拆成两组上下两行；倾斜校正 7 组参数分别加框；拆分对开页去掉不随翻页刷新的提示；添加页码预览加高 200px、Bates 加高 150px；PDF 加密权限另起一行、两个密码框铺满整行；文档信息、CA 签章、扁平化等模块的「使用建议」并入功能说明。

#### 收藏夹

- 首页卡片右上角星标常显，点击即收藏；「收藏夹」区块置顶显示（共 N 项），支持拖动卡片排序、导出 / 导入收藏配置、清空收藏。
- 收藏数据只存在浏览器 `localStorage`（键 `xcpdf.favorites`），不上传；删除模块后，旧收藏中失效的条目会自动清理。

- 修复**添加页码、Bates 编页**在 `/Rotate` 页面上的坐标偏移；修复添加页码「奇偶翻转」只影响预览、导出不生效，以及「加粗」勾选后预览与导出均无效果。

## 📂 一、页面管理（10 项）

### 🔗 1. 常规合并

多个 PDF 合并为一个，列表可拖拽调顺序。支持图片与 PDF 混合合并（图片按顺序等比缩放居中放入 A4）；勾选「发票模式」后逐文件检测，对 pdf-lib 复制后内容会丢失的特殊 PDF（如京东发票）自动转为图片合并，正常文件仍保留矢量文字。

### 🔀 2. 交替合并

两个及以上文件按 A-B-C-… 轮流穿插，适合双面扫描件、正反面材料合成。

### ✂️ 3. 常规拆分

五种拆法：按页码范围、按固定页数、拆成单页、奇偶页拆分、多组范围（多行文本，一行一组）。非法页码格式会弹窗提示，全角逗号自动转半角。

### 📑 4. 按书签拆分

读取 PDF 大纲，勾选需要的章节，按层级拆成多个文件；兼容具名目标（字符串 dest）书签。

### 💥 5. 按书签炸开

每个书签拆成一个独立文件，可限定最大拆分层级（1 = 一级书签，2 = 二级）；可选序号命名，位数按书签总数自动补零，保证按顺序排列。

### 📚 6. 页面重排

缩略图拖拽排序，支持拖入空白页，排序后导出新 PDF。

### 🔃 7. 页面倒序

一键反转整本页面顺序。

### 📄 8. 补齐空白页

三种插入方式（单选框切换，切换时只显示对应的设置行）：

- **补齐到偶数**：总页数为奇数时在末尾补 1 页，便于双面打印凑偶数。
- **指定位置插入**：填页码（支持 `2,5,7-9` 写法），并选择在该页**之前**或**之后**插入；预览条与状态文字会明确显示如「P1 后插入」「P5 前插入」。
- **隔页插入**：每隔 N 页插一页空白，同样可选插在该页**之前**或**之后**（便于单面打印后手工双面，或做笔记页）；提示区实时显示「共会插入 N 页空白」。

空白页尺寸默认**跟随前页**，也可强制 A4 / Letter；保留原文件元数据与书签，书签自动重映射到新页码。底部有插页预览条，空白页用虚线框标出并注明插入位置。

### 🗑️ 9. 删除页面

按页码移除指定页面，其余页面顺序不变。

### 🗑️ 10. 自动删空白页

按「非白色像素比例」检测疑似空白页，阈值可调（越低越严格），仅预览检测到的空白页供确认，可全选 / 反选，一键删除并另存；书签保留（页码不重新映射）。

扫描件可开启「忽略页边」裁掉上下各 N% 避开页眉页脚，或用「去噪」压掉扫描噪点；手动勾选过的页在调整阈值后不会被重置。

## 📐 二、页面调整（10 项）

### 🔄 11. 页面旋转·批量

按页码范围统一旋转 90° / 180° / 270°，适合整章扫描方向错误的情况。

### ↩️ 12. 页面旋转·逐页

逐页缩略图独立选择角度，完成后另存。

### 📚 13. 页面拼版

2 合 1 / 4 合 1 / 9 合 1，把多页缩排到一张纸上；「不足处理」与「边距」分两组设置，适合打印省纸。

### 📖 14. 小册子排版

按骑马订顺序重排页面，双面打印后对折装订即成小册子。

### 📖 15. 小册子拆分

把骑马订装订的 A3 扫描件（一张图含并排两页）切成单页并按正确页码重排；支持自动检测切分方向（横图左右切、竖图上下切），扫描图可拖拽排序、逐页旋转。

### 📏 16. 统一页面大小

把不同尺寸的页面统一为 A4 / A3 / 自定义尺寸；文字与矢量页面走矢量嵌入后按目标尺寸绘制，文字仍可选中搜索。扫描件按内嵌图像的原生像素封顶，不做无谓放大。

**页面方向**默认**跟随原页**——原页横向就输出横向、纵向就输出纵向，不再把横向内容压进纵向纸（旧版一律输出纵向）；也可强制「全部纵向」或「全部横向」。混排文档会输出横竖交替的页面。

### 📖 17. 拆分对开页

沿页面中线切开对开扫描页，支持 1~3 刀，每页可独立设置切割位置并拖动微调，可「应用到全部页」。

### 🧭 18. 倾斜校正

自动检测倾斜角度（±10° 内投影直方图搜索）或 0.1° 步进手动微调；校正后自动裁掉黑 / 白边并居中。输出分辨率可选 72 / 150 / 300 / 600 DPI，扫描件按原生像素封顶，不做无谓放大。

### 🔲 19. 裁剪白边

自动检测并裁掉页面四周空白。两种裁剪方式：

- **矢量裁剪**（默认）：只改页面的 CropBox，打开看到的就是裁好的页面，文字可选中 / 搜索，体积几乎不变（被裁掉的数据仍在文件里）；
- **栅格化裁剪**：整页转图片，连数据一起删除，文字不可搜索。

可设白色容差、四周微调（毫米数字框 + 滑块 + 拖动预览三向同步），输出尺寸支持「自动贴合内容 / 四周加页边距 / 固定页面尺寸」。

### 📄 20. 生成空白 PDF

按指定页数、纸张尺寸生成纯空白 PDF，支持多种纸张与自定义尺寸，便于拼接占位。

## 🖼️ 三、格式转换（3 项）

### 🖼️ 21. PDF转图片

逐页导出 PNG / JPG，可选分辨率（含高清档），支持单页另存或批量打包 ZIP；内置 CMap，离线也能正确渲染中文（含发票类 CID 字体）。

### 🧩 22. 图片转PDF

多张图片按自然顺序（1,2,…,10,11 而非字典序）合成 A4 文档，支持 JPG / PNG / **多页 TIFF**（逐页展开，等比缩放居中放入 A4），也可混合上传 PDF 并逐页展开后统一拼合。

### 📄 23. PDF提取文本

从文字层提取内容并导出 TXT，按坐标还原换行；页间可插入「第 N 页」标题行 / 分隔线 / 不插入，可保留段落或整段拼接；支持复制全文与保存 UTF-8 TXT。扫描件无文字层，结果为空。

## 🎨 四、图像处理（5 项）

### 📐 24. PDF 扁平化

把表单字段、注释、图层压成静态内容，防止二次编辑；页面大小可选原始尺寸或统一 A4，书签保留。扫描件按内嵌图像的原生像素封顶，不做无谓放大。

### 📸 25. 提取图片

自动扫描所有页面中的嵌入图片（照片、图章、Logo 等），以缩略图网格预览；可单张下载，也可打包 ZIP 批量下载。仅支持位图（JPEG / PNG），矢量图形无法提取。

### 🎨 26. 页面滤镜

黑白、锐化、反相，用于增强模糊扫描件；导出清晰度与原文件一致。

### 🟦 27. 工程蓝图

把任意 PDF 转成蓝底白线的蓝图效果，可调背景蓝深度与线条亮度，可选锐化，分辨率最高 12×（864 DPI）。输出为纯图像，文字不可选中。扫描件按原生像素封顶，不做无谓放大。

### 🖨️ 28. 模拟扫描件

给清晰 PDF 加上随机旋转、黑边、底色、噪点，模拟真实扫描件效果；旋转角度以「最大偏离幅度」统一控制（-2°~2°，默认 0.3°），预览与导出完全一致。输出分辨率可选，扫描件按原生像素封顶，不做无谓放大。

## 🔖 五、标注与编号（8 项）

### 🔢 29. 添加页码

自定义位置、字体大小、样式、起始页、颜色、是否加粗；支持「从第 X 页开始编号」（封面不编号）与奇偶页左右翻转，预览与导出一致。

**位置**用**九宫格**点选（左上 / 上中 / 右上 / 左中 / 居中 / 右中 / 左下 / 下中 / 右下），选中高亮；配合「距左/右边缘」「距上/下边缘」两个边距框精确定位——选在中间列或中间行时对应边距框自动禁用并提示「居中」。**页码方向**可旋转 0° / 90° / 180° / 270°，用于横竖混排的文档。`/Rotate` 页面的坐标映射与旋转补偿均已适配。

**中文页码**：支持「第 {num} 页」「第 {num} 页 / 共 {total} 页」「第 {num} 页，共 {total} 页」三种中文样式，用**宋体**渲染。由于 pdf-lib 内置字体不支持中文（直接写中文会静默变成问号），中文样式会转为图片嵌入，任何阅读器都能正确显示；英文与数字样式仍是真文字，可选中、可搜索。

### ⚖️ 30. Bates 编页

按法律文书惯例添加「前缀 + 连续编号 + 后缀」，可跨文件连续编号，支持 `/Rotate` 页面正确落位。

### 💧 31. 文字水印

自定义内容、角度、透明度、字号、颜色，可平铺；支持在预览上手动拖动定位，每页按自身实际尺寸定位。

### 🖼️ 32. 图片水印

使用本地图片作水印，可调透明度、旋转、缩放、平铺，手动拖动定位；旋转与混排尺寸问题已修复。

### 🧽 33. 删除水印

自动扫描全文，按**字号异常 / 半透明 / 非黑色 / 旋转 / 不可见 / Artifact / 每页重复**七类特征打分并分组，勾选后一次性移除，支持删除前后预览。**不做栅格化**：水印在内容流里就是独立的 `BT…ET` 文本块或 `Do` 图像块，直接从中抠掉，正文文字、书签、表单、链接与矢量质量全部保留。扫描完成后按置信度自动勾选候选，默认阈值针对真实文件调过，避免「扫描完成但一组都没选中」。

### 💮 34. 添加图章

在每页独立调整图章位置与大小，支持常规 / 正片叠底 / 变暗三种混合模式。导出时有两个并列出口：**「保存为可编辑PDF」**保留原有文字层与矢量内容，图章作为独立对象叠加，可在专业软件中移动 / 删除；**「导出不可编辑PDF」**把盖章页栅格化后重建（扫描页按原图像素、矢量页按 300dpi），图章成为页面像素，无法单独移除。

### 🔻 35. 扇形骑缝章

沿订口生成扇形分布的骑缝章效果，常用于合同防伪；切片坐标取整并关闭平滑，避免边缘黑线。导出与添加图章一致，两种出口并列：**「保存为可编辑PDF」**保留原文字层与书签，骑缝章作为独立图片叠加；**「导出不可编辑PDF」**整页栅格化重建，印章成为页面像素，无法单独移除。

### ✍️ 36. 批注

高亮、下划线、文本框、便签、圆形 / 椭圆 / 圆角矩形 / 填充框标记；边框色与填充色独立设置，填充透明度可调，图形带拖拽手柄。

## 🛡️ 六、安全与信息（8 项）

### 🖤 37. PDF涂黑（脱敏）

打开 PDF 后在预览上按住鼠标拖动画框，框住要隐藏的文字、印章或图片；支持逐页翻页、撤销上一个框、清空本页，黑框按页分别保存。填充色可自定义，导出分辨率可选 72 / 150 / 300 / 600 DPI，扫描件按原生像素封顶、不做无谓放大。点「涂黑并保存」后整本页面栅格化重建，被遮住的内容**永久删除、无法恢复**，原文件的文字层与表单不会带到新文件里（书签与文档信息会自动搬运），请务必另存为新文件。

### 📝 38. 文档信息

修改标题、作者、主题、关键词等元数据；单个字段清空也能正确保存。

### 🔏 39. CA签章查看

打开带数字签名的 PDF，列出所有签名域（名称、页码、外观），并在页面上用红框标出签名位置；多页时左侧带导航。

### 📑 40. 添加 / 编辑书签

- 打开即读入原大纲，左侧树形展示，右侧预览当前页；
- 新增 / 删除 / 双击改名，设定目标页与颜色（颜色写入 PDF，Acrobat 中显示为彩色书签）；
- 上移 / 下移调同级顺序，「设为子项 / 提升一级」调层级；
- 支持按标题搜索、撤销 / 重做（60 步）、导出 / 导入书签 JSON；
- 保存生成「原名-书签.pdf」，原文件不变。

### 🚫 41. 删除书签

一键移除 PDF 大纲（书签树），页面内容不变。

### 🗜️ 42. PDF压缩

预设档位或指定目标体积，程序自动迭代寻找在体积达标前提下画质最好的参数；压缩后自动重建完整大纲树，并保留书签颜色、加粗、斜体。栅格化模式对扫描件按原生像素封顶，不做无谓放大。

### 🔓 43. PDF解密

去除打开密码或权限限制；解密后保留原始矢量文字、书签与元数据，体积几乎不变，不再逐页光栅化。会识别「未加密 / 仅权限限制」状态。

### 🔐 44. PDF加密

添加打开密码与权限密码，可限制打印、复制、编辑、注释；加密后内容与排版不变，使用 `useObjectStreams: false` 保证最大兼容性。

| `pdf-lib.min.js`                             | `@cantoo/pdf-lib`，负责写入、加密解密、SVG 绘制              | ✅ 必需                                  |
| `jszip.min.js`                               | 批量导出打包 ZIP                                             | ✅ 必需                                  |
| `tiff.min.js`                                | TIFF 解码（UTIF + pako + canvas 封装，暴露 `window.TIFFKit`） | ✅ 必需（图片转 PDF / 合并用到 TIFF 时） |
