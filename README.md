# 📦 离线PDF工具箱 V7.2

> 纯离线 · 零上传 · 全免费 · 免安装 · 全平台通用

一个完全运行在浏览器端的 PDF 处理工具集。**现已升级为42 项功能**，无需安装软件，无需上传文件，打开就能用。

通吃 **Windows、Linux、macOS、安卓、iOS、国产麒麟系统**——只要有浏览器，它就能运行。

## 📦 更新日志

### [V7.2] - 2026-11-03

#### 新增

- 📄 **PDF 提取文本**：读取 PDF 的**文字层**，按文字坐标还原阅读顺序，尽量减少串行；页与页之间可插入「第 N 页」标题行、分隔线或什么都不插；可勾选「保留段落」，也可整段拼接不换行。结果直接显示在页面里，支持**一键复制**与**保存 UTF-8 TXT**（带 BOM，Windows 记事本直接可读）。已提取后再调整分隔符 / 排版只重组缓存文本，不重复解析文件。不修改原文件。
- 📑 **添加 / 编辑书签**：左侧书签树、右侧页面预览，工具栏在预览上方。打开 PDF 时自动读入原有大纲，可新增、删除、双击改名，随时调整目标页与颜色；上移 / 下移只调整同级顺序，「设为子项 / 提升一级」调整层级。书签颜色会写入 PDF，Acrobat 中即显示为彩色书签，重新打开也能读回。支持导出 / 导入书签 JSON、撤销 / 重做（60 步）、按标题搜索；保存生成「原名-书签.pdf」，原文件不变。

#### 界面统一（贯穿全站 42 个模块）

- **模块页面两段式骨架**：上段「左上传窗口（340px）+ 右功能说明（≤660px）」，下段「左设置列（300px）+ 右预览区」。页面重排、倒序、补齐空白页、删除页面、自动删空白页、批量 / 逐页旋转、页面拼版、小册子排版 / 拆分、裁剪白边等模块全部按此重排。
- **参数分组**：同一模块的参数按语义收进浅底圆角框（全站 43 组），不再平铺成长条。
- **预览窗口统一**：高度统一为 `clamp(420px, calc(100vh - 300px), 720px)`——大屏 720、矮屏自动收缩，保证预览和操作按钮同屏；带翻页的模块统一为「左翻页组 / 右缩放或提示」工具条，只翻页的模块不再出现多余缩放按钮。
- **页码文案统一**：全部改为「第 N / M 页」。
- **模块页标题加收藏星标**：42 个模块主界面标题旁可直接收藏，与首页卡片、收藏夹三处状态实时同步；星标紧贴标题文字，不飘到页面最右侧。
- **裁剪白边**：改为上下两段，下段三栏 2 : 2 : 6（白色容差 / 微调范围 / 预览），说明栏加宽到 400px；微调数值改为可直接输入的毫米数字框，与滑块、拖动预览框三者实时双向同步。
- **小册子拆分**：切分方向三个选项各占一行，左右栏比例 4 : 6；自动检测项注明「横图左右切、竖图上下切」。
- **其他修订**：页面拼版「不足处理」与「边距」拆成两组上下两行；倾斜校正 7 组参数分别加框；拆分对开页去掉不随翻页刷新的提示；添加页码预览加高 200px、Bates 加高 150px；PDF 加密权限另起一行、两个密码框铺满整行；文档信息、CA 签章、扁平化等模块的「使用建议」并入功能说明。

#### 收藏夹

- 首页卡片右上角星标常显，点击即收藏；「收藏夹」区块置顶显示（共 N 项），支持拖动卡片排序、导出 / 导入收藏配置、清空收藏。
- 收藏数据只存在浏览器 `localStorage`（键 `xcpdf.favorites`），不上传；删除模块后，旧收藏中失效的条目会自动清理。

#### 修复

- 修复**扇形骑缝章**多页覆盖与 `/Rotate` 页面坐标偏移。
- 修复**添加页码、Bates 编页**在 `/Rotate` 页面上的坐标偏移；修复添加页码「奇偶翻转」只影响预览、导出不生效，以及「加粗」勾选后预览与导出均无效果。
- 修复**统一页面大小**：文字 / 矢量页面需要缩放时必定报错并让按钮锁死的问题（原先把页面对象当成可绘制对象）；处理失败时也会给出提示并自动恢复按钮。
- 修复**删除页面、自动删除空白页、页面旋转·批量、页面旋转·逐页**：重新打开另一个文件后，大图预览与翻页数量会累积上一次页面；现在每次载入文件都会重建预览。
- 修复**图片水印**旋转 90° 后被拉伸变形；A4/A3、横竖混排文档中后续页水印位置偏移；平铺模式预览与导出起点不一致。**文字水印**的混合尺寸定位同步修复，每页按自身实际尺寸定位。
- 修复**工程蓝图**导出的 PDF 纸张尺寸随渲染倍率一起放大（约 2 倍）：保留高清图像，页面物理尺寸与原页一致。
- 修复**页面重排**：未添加真实 PDF、只添加过空白页时，再次添加空白页会报错。
- 修复**小册子拆分**：旋转页面后点放大镜，大图预览不显示。
- 修复**按书签炸开**完成数量与实际生成文件数不一致；**元数据编辑**单独清空某个字段保存后又被原值填回；**添加 / 编辑书签**清空全部后无法按提示保存无书签 PDF。
- 修复**PDF 转图片**批量下载中任意一页失败会中断整批、进度条卡住且按钮不恢复。
- 修复公共大图预览在快速翻页时图片、页码与说明错位；修复反复导入多页 TIFF 后图片地址未回收导致的潜在内存增长。
- 代码梳理：移除重复工具函数与未使用变量、空事件监听，公共逻辑统一收敛到 `ToolUtils`。

#### 字体兼容与安全加固

- **内置全套 CMap（168 个）**：替换原先只含 5 个简体横向 CMap 的精简包。对「只写字体名 + 预定义 CMap、不嵌入字体」的 PDF（如部分政务/银行导出文件），文本不再乱码，页面不再空白或方块。Word 等自带字体的 PDF 表现不变。
- **恶意 PDF 防护（双重）**：新增页面级 CSP（`script-src` 不含 `unsafe-eval`，`object-src 'none'`），同时在 pdf.js 加载参数中设置 `isEvalSupported: false`，关闭字形指令的动态编译。即便 PDF 内嵌针对 CVE-2024-4367 的构造字体，打开文件也不会执行任何注入代码。
- **图章 / 骑缝章提供两种导出**：**「保存为可编辑PDF」**保留原文字层、矢量内容与书签，印章作为独立对象叠加；**「导出不可编辑PDF」**把盖章后的页面逐页栅格化再重建 PDF，印章成为页面像素，Acrobat 等软件无法再单独选中、移动或删除。栅格化时扫描页按原图分辨率输出，矢量页按 300dpi 输出；未盖章页也会一并栅格化，页序、书签、元数据保持不变。

### [V7.0] - 2026-09-13

#### 新增

- 🗑️ **自动删除空白页**：自动检测 PDF 中的疑似空白页（非白色像素比例低于阈值），仅预览检测到的空白页供用户确认，支持灵敏度调节、全选/反选，一键删除并保存为去除空白页的新 PDF。书签将保留。
- 📖 **小册子拆分**：将骑马订装订的扫描件（一张图含两页并排）自动拆分为单页，并按正确页码顺序重排。支持自动检测切分方向（左右/上下）、拖拽调整扫描图顺序、逐页旋转，适用于拆开订书钉后用 A3 扫描仪扫描的文档。
- 🖋️ **CA 签章查看**：打开带数字签名的 PDF，自动列出所有签名域（名称、页码、外观），并在页面上用红框高亮签名位置。感谢 GitHub 用户 [gitca233](https://github.com/gitca233/offline-pdf-tools) 贡献此模块。

#### 优化

- **常规合并新增发票模式**：勾选后逐文件检测，对 pdf-lib 复制后内容丢失的特殊 PDF（如京东发票）自动转为图片合并，正常文件仍保留矢量文字，兼顾兼容性与清晰度。
- **常规合并支持图片与 PDF 混合合并**：图片自动等比缩放居中放入 A4 页面，按列表顺序与 PDF 合并，并跳过发票检测以节省算力。
- **添加页码模块增强**：
  - 新增“从第 X 页开始编页码”功能，适用于封面不编页码、不显示页码的场景。
  - 新增“翻转左右页码位置”按钮，可手动调节奇偶页页码左右位置，解决双面打印时页码位置不符合预期的问题。
- **图章混合模式**：添加图章和扇形骑缝章两个模块新增 3 种混合模式——**常规**（直接覆盖页面）、**正片叠底**（模拟真实盖章效果，白底印章最佳）、**变暗**（白底纯红印章接近正片叠底效果）。用户可根据印章类型和页面背景选择最佳模式。
- **拆分对开页新增 1X 模式**：用于生成体积更小的 PDF 文件。
- **图片转 PDF 大幅优化**：未旋转的 JPG/PNG 图片直接嵌入原文件，不再经过 Canvas 转码，转换速度显著提升，JPG 转出的 PDF 体积不再膨胀数倍。
- **批注功能增强**：新增圆形、椭圆、圆角矩形、填充框等标记工具，边框色与填充色独立设置，填充透明度独立调节，工具参数按需显示，操作更聚焦。
- **模拟扫描件模块调整**：旋转控制改为“最大偏离幅度”（-2~2°，默认 0.3°），所有页面统一使用同一个角度，调整幅度时所有页面统一调整，移除了手动微调单页角度功能，导出结果与预览完全一致。
- **PDF 压缩支持限定目标体积**：设定期望大小后，程序自动迭代寻找最清晰的压缩参数，在体积达标的前提下尽量保留画质。
- **按书签炸开支持选择拆分层级**：可指定最大拆分层级（1 代表一级书签，2 代表二级书签），按需控制拆分深度，避免层级过深导致文件过多。

#### 修复

- 修复**删除页面**模块中，点击图片右上角放大镜图标无预览的问题。
- 修复**加密和解密**模块在某些情况下失败的问题。
- 修复**扇形骑缝章**从第 2 页开始印章上出现黑线的问题。原因是切片坐标使用小数，导致 PNG 透明边缘中的黑色像素被切到。修复后坐标全部取整并关闭图片平滑，黑线消失。

- 修复**页面滤镜**模块导出 PDF 时因渲染分辨率过低导致画面模糊（马赛克）的问题，现在输出清晰度与原文件一致。

### [V6.0 · 35 项版] - 2026-08-06

#### 新增（在 V5.0 基础上扩展至 35 项）
- 📄 **生成空白 PDF**：按指定页数 / 尺寸生成纯空白 PDF，便于拼接占位。
- 📄 **补齐空白页**：批量补齐，使每个文档页数达到指定值（如装订对齐）。
- ✂️ **裁剪白边**：自动检测并裁掉页面四周的空白边距，输出紧凑版 PDF（可设留白阈值与边距）。
- 📏 **统一页面大小**：将不同尺寸的页面统一为同一页面尺寸（A4 / 自定义）。
- 🪪 **删除书签**：一键移除 PDF 大纲（书签树），不改变页面内容。
- 🔢 **Bates 编页**：按法律文书惯例为每页添加连续 Bates 编号（前缀 + 编号 + 后缀）。
- 🪡 **扇形骑缝章**：沿订口生成沿中缝分布的扇形骑缝章效果，常用于合同骑缝防伪。
- 📄 **PDF 扁平化**：将表单字段、注释、图层合并为静态内容，防止被二次编辑。
- 🖨️ **模拟扫描件**：将清晰 PDF 处理成类似真实扫描件的效果（噪点 / 模糊 / 阴影等），用于演示或脱敏。
- 🖊️ **批注**：在 PDF 上添加高亮、下划线、文本框等批注。
- 🧭 **倾斜校正（Deskew）**：自动或手动检测页面倾斜角度（±10° 内投影直方图法自动搜索，或 0.1° 步进手动微调），校正后自动裁剪黑/白边并居中。
- 🟦 **工程蓝图**：将任意 PDF 转换为蓝图风格（蓝底白线），支持彩色扫描件、灰度图纸、黑白线条图自动适配。可调节背景蓝深度和线条亮度，可选锐化增强模糊图纸清晰度，右侧实时预览所见即所得。转换后文件为纯图像，文字不可选中/搜索。


#### 优化
- 界面细节与样式微调（阴影、圆角、过渡曲线），并新增 `prefers-reduced-motion` 降低动效支持。
- **PDF 压缩支持保留原书签**：压缩后自动重建完整大纲树，支持多级嵌套书签，点击目录可跳转到对应页面。使用底层 PDF 对象构建，兼容所有 pdf‑lib 版本及 Acrobat、Chrome 等主流阅读器，已通过 Acrobat 兼容性专项验证

- **图片转 PDF 支持混合上传**：可同时选择图片与 PDF，上传的 PDF 会自动**逐页展开**并插入到预览列表（按选择顺序排列），与图片统一拼合输出

## 📂 一、页面管理（10 项）

### 🔗 1. 常规合并

多个 PDF 合并为一个，列表可拖拽调顺序。支持图片与 PDF 混合合并（图片按顺序等比缩放居中放入 A4）；勾选「发票模式」后逐文件检测，对 pdf-lib 复制后内容会丢失的特殊 PDF（如京东发票）自动转为图片合并，正常文件仍保留矢量文字。

### 🔀 2. 交替合并

两个及以上文件按 A-B-C-… 轮流穿插，适合双面扫描件、正反面材料合成。

### ✂️ 3. 常规拆分

五种拆法：按页码范围、按固定页数、拆成单页、奇偶页拆分、多组范围（多行文本，一行一组）。非法页码格式会弹窗提示，全角逗号自动转半角。

### 📑 4. 按书签拆分

读取 PDF 大纲，勾选需要的章节，按层级拆成多个文件；兼容具名目标（字符串 dest）书签。

### 💥 5. 按书签炸开

每个书签拆成一个独立文件，可限定最大拆分层级（1 = 一级书签，2 = 二级）；可选序号命名，位数按书签总数自动补零，保证按顺序排列。

### 📚 6. 页面重排

缩略图拖拽排序，支持拖入空白页，排序后导出新 PDF。

### 🔃 7. 页面倒序

一键反转整本页面顺序。

### 📄 8. 补齐空白页

批量补齐，使每个文档页数达到指定值（如装订对齐、双面打印凑偶数）。

### 🗑️ 9. 删除页面

按页码移除指定页面，其余页面顺序不变。

### 🗑️ 10. 自动删空白页

按「非白色像素比例」检测疑似空白页，阈值可调（越低越严格），仅预览检测到的空白页供确认，可全选 / 反选，一键删除并另存；书签保留（页码不重新映射）。

## 📐 二、页面调整（10 项）

### 🔄 11. 页面旋转 · 批量

按页码范围统一旋转 90° / 180° / 270°，适合整章扫描方向错误的情况。

### ↩️ 12. 页面旋转 · 逐页

逐页缩略图独立选择角度，完成后另存。

### 📚 13. 页面拼版

2 合 1 / 4 合 1 / 9 合 1，把多页缩排到一张纸上；「不足处理」与「边距」分两组设置，适合打印省纸。

### 📖 14. 小册子排版

按骑马订顺序重排页面，双面打印后对折装订即成小册子。

### 📖 15. 小册子拆分

把骑马订装订的 A3 扫描件（一张图含并排两页）切成单页并按正确页码重排；支持自动检测切分方向（横图左右切、竖图上下切），扫描图可拖拽排序、逐页旋转。

### 📏 16. 统一页面大小

把不同尺寸的页面统一为 A4 / A3 / 自定义尺寸；文字与矢量页面走矢量嵌入后按目标尺寸绘制，文字仍可选中搜索。

### 📖 17. 拆分对开页

沿页面中线切开对开扫描页，支持 1~3 刀，每页可独立设置切割位置并拖动微调，可「应用到全部页」。

### 🧭 18. 倾斜校正

自动检测倾斜角度（±10° 内投影直方图搜索）或 0.1° 步进手动微调；校正后自动裁掉黑 / 白边并居中。

### 🔲 19. 裁剪白边

自动检测并裁掉页面四周空白。两种裁剪方式：

- **矢量裁剪**（默认）：只改页面的 CropBox，打开看到的就是裁好的页面，文字可选中 / 搜索，体积几乎不变（被裁掉的数据仍在文件里）；
- **栅格化裁剪**：整页转图片，连数据一起删除，文字不可搜索。

可设白色容差、四周微调（毫米数字框 + 滑块 + 拖动预览三向同步），输出尺寸支持「自动贴合内容 / 四周加页边距 / 固定页面尺寸」。

### 📄 20. 生成空白 PDF

按指定页数、纸张尺寸生成纯空白 PDF，可选格线、页眉页脚，便于拼接占位。

## 🖼️ 三、格式转换（3 项）

### 🖼️ 21. PDF 转图片

逐页导出 PNG / JPG，可选分辨率（含高清档），支持单页另存或批量打包 ZIP；内置 CMap，离线也能正确渲染中文（含发票类 CID 字体）。

多张图片按自然顺序（1,2,…,10,11 而非字典序）合成 A4 文档，支持 JPG / PNG / **多页 TIFF**（逐页展开，等比缩放居中放入 A4），也可混合上传 PDF 并逐页展开后统一拼合。

### 📄 23. PDF 提取文本

从文字层提取内容并导出 TXT，按坐标还原换行；页间可插入「第 N 页」标题行 / 分隔线 / 不插入，可保留段落或整段拼接；支持复制全文与保存 UTF-8 TXT。扫描件无文字层，结果为空。

## 🎨 四、图像处理（5 项）

### 📐 24. PDF 扁平化

把表单字段、注释、图层压成静态内容，防止二次编辑；页面大小可选原始尺寸或统一 A4，书签保留。

自动扫描所有页面中的嵌入图片（照片、图章、Logo 等），以缩略图网格预览；可单张下载，也可打包 ZIP 批量下载。仅支持位图（JPEG / PNG），矢量图形无法提取。

黑白、锐化、反相，用于增强模糊扫描件；导出清晰度与原文件一致。

### 🟦 27. 工程蓝图

把任意 PDF 转成蓝底白线的蓝图效果，可调背景蓝深度与线条亮度，可选锐化，分辨率最高 12×（864 DPI）。输出为纯图像，文字不可选中。

### 🖨️ 28. 模拟扫描件

给清晰 PDF 加上随机旋转、黑边、底色、噪点，模拟真实扫描件效果；旋转角度以「最大偏离幅度」统一控制（-2°~2°，默认 0.3°），预览与导出完全一致。

## 🔖 五、标注与编号（7 项）

### 🔢 29. 添加页码

### ⚖️ 30. Bates 编页

按法律文书惯例添加「前缀 + 连续编号 + 后缀」，可跨文件连续编号，支持 `/Rotate` 页面正确落位。

### 💧 31. 文字水印

自定义内容、角度、透明度、字号、颜色，可平铺；支持在预览上手动拖动定位，每页按自身实际尺寸定位。

### 🖼️ 32. 图片水印

使用本地图片作水印，可调透明度、旋转、缩放、平铺，手动拖动定位；旋转与混排尺寸问题已修复。

### 💮 33. 添加图章

在每页独立调整图章位置与大小，支持常规 / 正片叠底 / 变暗三种混合模式。导出时有两个并列出口：**「保存为可编辑PDF」**保留原有文字层与矢量内容，图章作为独立对象叠加，可在专业软件中移动 / 删除；**「导出不可编辑PDF」**把盖章页栅格化后重建（扫描页按原图像素、矢量页按 300dpi），图章成为页面像素，无法单独移除。

### 🔻 34. 扇形骑缝章

沿订口生成扇形分布的骑缝章效果，常用于合同防伪；切片坐标取整并关闭平滑，避免边缘黑线。导出与添加图章一致，两种出口并列：**「保存为可编辑PDF」**保留原文字层与书签，骑缝章作为独立图片叠加；**「导出不可编辑PDF」**整页栅格化重建，印章成为页面像素，无法单独移除。

### ✍️ 35. 批注

高亮、下划线、文本框、便签、圆形 / 椭圆 / 圆角矩形 / 填充框标记；边框色与填充色独立设置，填充透明度可调，图形带拖拽手柄。

去除打开密码或权限限制；解密后保留原始矢量文字、书签与元数据，体积几乎不变，不再逐页光栅化。会识别「未加密 / 仅权限限制」状态。

### 🔐 42. PDF 加密

添加打开密码与权限密码，可限制打印、复制、编辑、注释；加密后内容与排版不变，使用 `useObjectStreams: false` 保证最大兼容性。
